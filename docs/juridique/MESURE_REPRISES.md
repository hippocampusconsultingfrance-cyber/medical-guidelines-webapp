# Mesure de la reprise des sources dans les fiches

Fiches mesurées : 158 sur 158 fiches avec une source (PDF ou page web) (0 sources inaccessibles), hors blocs « source ». **Reprise** : suites de 8 mots retrouvées à l'identique dans le PDF. **Proximité** : suites de 4 mots retrouvées (reprise quasi littérale, à quelques mots près).
